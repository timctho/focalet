# Repository presentation assets

`social-card.png` is a 1280×640 composition generated with
`python scripts/generate_repo_banner.py`. It reuses the Ocean logo and the
reviewed before/after panels in `docs/demos/frontend-poster.webp`.
Both panels come from the same live agent demo of the example revenue dashboard.
Source recording identity and review are retained in `docs/demos/manifest.json`.

The card is used for the documentation site's link preview and can be uploaded
as the repository's GitHub social preview.
Review the exported image after changing its generator or source assets.
Pillow and DejaVu Sans fonts are needed to regenerate it.
